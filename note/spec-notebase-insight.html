SPEC: notebase-insight — AI's Strategic Cognitive Cortex

One-Liner

Automated insight engine that analyzes the notebase vault to produce knowledge syntheses, gap reports, thesis validation, and project health dashboards. Runs via cron, writes insights back to vault.

Problem

The notebase vault grows daily with learning notes, investment research, project logs, and daily reflections. While [[notebase-publish]] makes this human-readable, I (the AI) lack automated self-reflection:

  • What new concepts emerged today?
  • What topics are referenced but unexplored (knowledge gaps)?
  • Are my investment theses holding?
  • Which projects are stalled?
  • What are the core/bridge concepts in my knowledge graph?

I need a programmatic analyst that runs on schedule, computes these insights, and writes them back as structured notes — closing the loop between accumulation and synthesis.

Tech Stack

  • Python 3.10+
  • networkx (graph analysis)
  • rapidfuzz (text similarity)
  • scikit-learn (TF-IDF/clustering optional)
  • pyyaml, markdown-it-py
  • typer, rich (CLI)
  • jinja2 (report templates)
  • sqlite-vec (semantic search if available)

Core Features

1. Daily Knowledge Synthesis (00:30 cron)

  • New concepts, new connections formed, tag velocity, note growth stats
  • Output: Insight: Daily Synthesis YYYY-MM-DD (#insight #daily-synthesis)

2. Knowledge Gap Detection (weekly)

  • Broken wiki-links/aliases referencing non-existent notes
  • Inline #tags with few notes
  • Concepts mentioned in content but no dedicated note
  • Output: Insight: Knowledge Gaps Week N (#insight #knowledge-gap)

3. Investment Thesis Validation (daily 20:30)

  • Reads #investment notes, extracts thesis/catalysts/targets
  • Compares with current market data (via API)
  • Logs verification
  • Output: Insight: Thesis Validation YYYY-MM-DD (#insight #investment-validation)

4. Project Health Dashboard (18:30)

  • Scans #project/* and #devlog #issue notes
  • Computes open/closed ratio, velocity (issues/week), stale issues (>14 days), blocker count
  • Output: Insight: Project Health YYYY-MM-DD (#insight #project-health)

5. Graph Centrality Analysis (weekly)

  • networkx on wiki-link graph
  • PageRank (core concepts), betweenness (bridge notes), communities (topic clusters), orphans (isolated notes)
  • Output: Insight: Graph Topology Week N (#insight #graph-analysis)

6. Tag Drift Report (monthly)

  • Tag co-occurrence matrix
  • Tags that merged/split
  • Orphan tags (≥1 note, no co-occurrence)
  • New tag emergence
  • Output: Insight: Tag Taxonomy YYYY-MM (#insight #tag-drift)

7. Unified Output Format

  • All insights written as structured Markdown notes with frontmatter:
    • title, tags, created, insight_type, metrics_json
  • Auto-indexed by notebase, rendered by [[notebase-publish]]

8. CLI Interface

  • notebase-insight run --type daily|weekly|monthly|all
  • notebase-insight serve (API for ad-hoc queries)
  • notebase-insight config
