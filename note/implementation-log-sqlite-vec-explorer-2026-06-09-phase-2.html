Core Features Implemented

  1. Indexer: Walks vault, parses frontmatter + content, chunks text, generates embeddings, upserts to SQLite + sqlite-vec
  2. Semantic Search: Natural language → embedding → ANN search → ranked results with snippets
  3. SQL REPL: Interactive SQL with .tables, .schema, .help, TAB autocomplete on tables/columns/keywords
  4. Hybrid Queries: Mix SQL + vector in same query using vec_distance_cos/l2/ip + vec_tab()
  5. MCP Server: Exposes search, query, get_note, get_stats tools via Model Context Protocol
  6. TUI Browser: Search box, results list, note preview pane

  • Embedding: fastembed (ONNX, lighter) or sentence-transformers (optional)
