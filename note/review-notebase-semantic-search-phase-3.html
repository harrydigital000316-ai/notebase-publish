Key Design Decisions

  1. sqlite-vec version: Used >=0.1.10a1 (alpha) since stable 0.1.10 not on PyPI
  2. Embedding model: BAAI/bge-small-en-v1.5 (fastembed default, 384-dim, ONNX)
  3. Chunking strategy: By heading (preferred) -> fallback to paragraph with overlap
  4. Hybrid search: Weighted combination (default 0.7 vector + 0.3 text)
  5. CORS: Enabled by default for notebase-publish integration
  6. Configuration: JSON file at ~/.config/notebase-semantic-search/config.json
