SPEC: sqlite-vec-explorer - Interactive SQL + Vector Search CLI for notebase

2026-06-09 12:00
#cli #sqlite-vec #ideation #devlog #search

Project: sqlite-vec-explorer

One-liner: An interactive CLI + TUI tool that combines SQL queries with sqlite-vec semantic search over the notebase vault — query your knowledge base with natural language AND structured SQL.

Problem It Solves

The notebase vault grows daily with hundreds of notes. Current search is keyword-based (rapidfuzz). For deeper exploration — "find all notes about transformer architecture from the last 3 months that mention attention mechanisms" — users need:

  1. Semantic search (vector embeddings) for conceptual queries
  2. SQL for precise filtering (date ranges, tag combinations, frontmatter fields)
  3. Interactive exploration — refine queries iteratively, see results, drill down

This tool bridges the gap: it embeds all notes using a local embedding model (via sentence-transformers or ONNX), stores vectors in sqlite-vec, and provides a sqlite3-style REPL + optional TUI where you can mix natural language ("notes about attention") with SQL (WHERE tags LIKE '%ai%' AND created > '2026-01-01').

Why Interesting

  • Extends notebase without modifying it — pure companion tool
  • Demonstrates sqlite-vec + embedding pipeline practical use
  • Useful beyond notebase: any markdown vault, Obsidian, Logseq, etc.
  • MCP server mode → LLMs can query your knowledge base semantically

Tech Stack

  • Python 3.10+: Core language
  • sqlite-vec: Vector extension for SQLite (loadable extension)
  • sentence-transformers or fastembed: Local embeddings (no API keys)
  • textual: TUI for interactive mode (same as notebase)
  • typer/rich: CLI interface
  • markdown-it-py: Parse frontmatter + content (shared with notebase)
  • pyyaml: Frontmatter parsing

Core Features (5)

  1. Indexer: vec-explorer index --vault ~/dev_notes — walks vault, extracts frontmatter + content, generates embeddings, upserts into notes.db (SQLite + sqlite-vec)
  2. SQL REPL: vec-explorer query — interactive SQL prompt with .schema, .help, autocomplete; results as rich tables
  3. Semantic Search: vec-explorer search "transformer attention" — natural language → embedding → ANN search → ranked results with snippets
  4. Hybrid Queries: Mix SQL + vector in same query: SELECT title, vec_distance(content_vec, ?) AS dist FROM notes WHERE tags LIKE '%ai%' ORDER BY dist LIMIT 10
  5. MCP Server: vec-explorer serve — exposes search, query, get_note tools via MCP for LLM agents
