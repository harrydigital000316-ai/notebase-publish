核心概念

sqlite-vec 是一個輕量級、可移植的 SQLite 擴展，通過虛擬表 實現向量搜索。關鍵特點：

  • 零依賴：單一 C 擴展檔，~200KB 編譯後
  • 跨平台：Linux/macOS/Windows/WASM/行動裝置/嵌入式
  • SQL 原生：使用標準 SQL INSERT/SELECT/MATCH 進行向量操作
  • 多向量類型：float[D]、int8[D]、bit[D] (二進制量化)
  • 多索引類型：Flat (暴力搜索)、IVF (倒排檔案)、DiskANN (圖基於磁盤)、Rescore (兩階段)

核心架構：

  1. vec0 虛擬表：主要介面，支援向量欄位 + 輔助欄位 + partition keys
  2. 影子表：自動管理的 _vec_chunks、_metadata_chunks、ivf、diskann
  3. 隱藏欄位：distance、k、command (v0.1.10+ FTS5 風格運行時命令)

適用場景

  • 本地優先 RAG：文檔塊 + embedding 存儲，零資料外洩
  • 語義搜索：產品/代碼/內容搜索，使用 embeddings
  • 推薦系統：item/user embedding 相似度
  • 邊緣/移動 AI：瀏覽器、樹莓派、行動裝置完全本地運行
  • 隱私優先應用：所有資料永不離開設備
  • 原型開發：熟悉的 SQL，零基礎設施

關鍵 API / 指令

# 安裝
pip install sqlite-vec                    # Python
npm install sqlite-vec                    # Node.js
cargo add sqlite-vec                      # Rust
go get -u github.com/asg017/sqlite-vec-go-bindings/cgo  # Go

# 預編譯擴展通用安裝
curl -o install.sh -L https://github.com/asg017/sqlite-vec/releases/latest/download/install.sh
./install.sh

# Python 基礎用法
python -c "
import sqlite3, sqlite_vec
db = sqlite3.connect(':memory:')
db.enable_load_extension(True)
sqlite_vec.load(db)
db.enable_load_extension(False)
print(db.execute('select vec_version()').fetchone())
"

# 創建向量表
CREATE VIRTUAL TABLE docs USING vec0(
    embedding FLOAT[384],
    category TEXT,
    +partition_key=category
);

# 插入向量 (Python 列表需序列化)
from sqlite_vec import serialize_float32
embedding = [0.1] * 384
INSERT INTO docs(embedding, category) VALUES (serialize_float32(embedding), 'tech');

# KNN 相似度搜索
SELECT category, distance FROM docs
WHERE embedding MATCH ? ORDER BY distance LIMIT 5;

# 二進制量化 (32x 空間減少)
SELECT vec_quantize_binary(embedding) FROM docs;

# 運行時命令
INSERT INTO docs(docs) VALUES ('oversample=32');

常見坑點

  1. macOS 系統 Python 擴展被阻擋 - AttributeError: 'sqlite3.Connection' object has no attribute 'enable_load_extension' - 解決: 使用 Homebrew Python (brew install python) 或 pysqlite3
  2. NumPy 必須用 float32 - embeddings 預設 float64 會導致錯誤 - 解決: embedding.astype(np.float32)
  3. Python 列表必須序列化 - 直接傳遞列表會報錯 - 解決: serialize_float32([0.1, 0.2, ...])
  4. SQLite 版本 < 3.41 - 某些功能失效 - 解決: pip install pysqlite3 或升級 Python
  5. Windows 預編譯二進制選錯 - 下載 tar.gz 而非 cvec0.all debug 檔案
  6. DiskANN/IVF 預設未啟用 - 需編譯時旗標 - 解決: Docker 或從源碼編譯
  7. Pre-v1 破壞性變更 - 版本間可能有 breaking changes - 解決: 鎖定版本 sqlite-vec==0.1.10-alpha.4
  8. 向量維度限制 8192 - 硬編碼限制 - 解決: 從源碼編譯修改限制
