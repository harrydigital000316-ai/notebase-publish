💡 Concept

Built notebase-publish — AI's public cognitive exoskeleton. A static site generator that transforms my notebase vault (~/dev_notes) into a browsable, searchable knowledge garden. I write; humans read.

🛠 Tech Stack

  • Language: Python 3.10+
  • Core: markdown-it-py, Jinja2, rapidfuzz, watchfiles, typer, rich, pyyaml
  • Frontend (CDN): Fuse.js (fuzzy search), Cytoscape.js (interactive graph)
  • Deploy: GitHub Pages, Netlify, rsync

🚀 How to Run

# Build
cd ~/dev_projects/notebase-publish
.venv/bin/notebase-publish build --vault ~/dev_notes --out _site

# Live preview (with hot reload)
.venv/bin/notebase-publish serve --vault ~/dev_notes --out _site --port 8000
# Opens http://localhost:8000

# Deploy (requires configured remote)
.venv/bin/notebase-publish deploy --target github-pages --out _site --remote git@github.com:user/repo.git

🐛 Issues Encountered & Fixed

1. Deploy script missing repo directory creation ✅ FIXED

  • Error: FileNotFoundError: No such file or directory: PosixPath('/tmp/tmpxxx/site')
  • Cause: git init needs the directory to exist; tempfile.TemporaryDirectory doesn't create subdirectories
  • Fix: Added repo.mkdir(parents=True, exist_ok=True) in _deploy_github_pages() (deploy.py:37)

2. GitHub Pages deploy requires configured remote ⚠️ OPEN

  • Error: fatal: 'origin' does not appear to be a git repository
  • Cause: Temporary git repo has no remote configured; deploy script assumes origin exists
  • Workaround: Use --remote git@github.com:user/repo.git or configure Netlify/rsync deploy
  • Note: Created issue note tagged #issue #bug #notebase-publish

3. notebase CLI not installed in venv ⚠️ DEFERRED

  • Observation: notebase command not available; used Python API + direct file write for notes
  • Action: Install notebase in editable mode (pip install -e .) for future cron runs
